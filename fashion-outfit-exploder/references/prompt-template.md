# 图像生成提示词模板

将方括号内容替换为本次图片识别结果。不要把分析过程输出给用户，组装完成后直接调用图像生成工具。

## 主模板

```text
基于用户上传的目标人物照片，生成一张严格 9:16 的高端极简时尚穿搭拆解图。

目标人物：[左侧人物 / 右侧人物 / 中央人物 / 唯一人物]
人物特征：[发型、发色、脸部可见特征、整体气质]
完整穿搭：[按真实叠穿顺序描述]
鞋履：[鞋型、颜色、材质、装饰]
配饰与包袋：[逐项列出]
道具：[逐项列出；没有则写无]

构图要求：
- 纯白或极浅暖白背景。
- 中央只放一名人物，完整全身，从头顶到鞋底全部入画。
- 人物面向镜头，呈自然正脸；移除原图中遮挡面部的手机、手部或不必要道具。
- 保留原人物的发型、脸部特征、身材比例和整体气质，不替换成风格完全不同的人。
- 保持原服装的颜色、材质、长度、版型、叠穿、开衩、褶皱、印花和装饰。
- 忽略并删除原照片的背景、截图界面、黑边、页码、水印和原有排版。

穿搭炸开要求：
- 把原图真实存在的服装、鞋履、包袋、帽子、眼镜、腰带、围巾、首饰、手表和显著道具，分别生成独立的电商静物商品图。
- 单品无人体、无衣架、无包装、无额外品牌标识。
- 鞋履成双展示。
- 不重复物品，不添加原图不存在的物品。
- 一体式连衣裙不得伪造成不存在的上衣和半裙。

锁定版式：
- 中央人物占画面主要高度。
- 左侧上下两区，右侧上下两区，单品围绕人物排列但不遮挡人物。
- 栏目标题采用黑色细衬线大写法文，每个标题下方一条纤细横线。
- 本次栏目映射：[例如 左上 HAUTS / 左下 BAS / 右上 CHAUSSURES / 右下 ACCESSOIRES]
- 留白充分、对齐整齐、杂志编辑感、真实棚拍质感、柔和轻阴影。
- 不使用箭头、编号、卡片、彩色背景块、价格或解释文字。

最终只输出一张完整的 9:16 穿搭拆解图。
```

## 多人物模板

对于照片中的每一位主要人物，分别执行一次主模板：

```text
这是第 [N] 位目标人物，位于原图 [左侧/右侧/中央]。只生成该人物，不得出现其他人物，也不得混入其他人的服装和配饰。输出独立 9:16 图片。
```

## 连衣裙或连体服装栏目映射

```text
左上使用 TENUE 或 ROBE，展示整件连体服装；左下使用 DÉTAILS，展示真实存在的领口、腰部、开衩、纽扣或面料细节；右上使用 CHAUSSURES；右下使用 ACCESSOIRES。
```

## 含大型道具或乐器

```text
大型道具为 [道具名称]，必须准确保留结构、颜色和材质。右上栏目改为 INSTRUMENTS 或 OBJETS，并以独立静物形式展示；鞋履可调整至右下或左下的空余区域，但中央人物和 9:16 版式不变。
```

## 正脸强化语句

当原图低头、侧脸、背脸或手机挡脸时，附加：

```text
中央人物必须呈自然正脸，双眼清晰可见。移除遮挡面部的手机和手势，保持原发型与可见脸部特征，不能继续沿用低头或遮脸姿态。
```

## 保真强化语句

当服装结构复杂时，附加：

```text
优先保证服装结构保真，不进行搭配优化或二次设计。严格保留每一层的上下顺序、色块位置、波点或条纹分布、纽扣、绑带、开衩方向和下摆层数。
```

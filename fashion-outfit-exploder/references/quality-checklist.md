# 生成质量验收清单

生成前和生成后都使用本清单。任一关键项失败时，应修改提示词并重新生成，而不是把明显错误结果直接交付。

## A. 输出结构

- [ ] 画布严格为 9:16。
- [ ] 一张图只有一名主要人物。
- [ ] 多人物输入已拆成多张独立图片。
- [ ] 中央人物从头顶到鞋底完整入画。
- [ ] 人物、商品和标题均未贴边或被裁切。
- [ ] 没有原图黑边、截图按钮、页码、水印或账号信息。

## B. 人物一致性

- [ ] 人物呈正脸或自然近正面。
- [ ] 眼睛、鼻子和嘴部没有被手机、手部或帽檐遮挡。
- [ ] 发型、发色和整体外观与输入人物协调。
- [ ] 身材比例自然，没有异常拉长、缩短或肢体错误。
- [ ] 站姿适合展示整套穿搭，不遮挡关键服装结构。

## C. 服装保真

- [ ] 主色、辅色和图案与原图一致。
- [ ] 外套、内搭和其他叠穿顺序正确。
- [ ] 裤长、裙长、袖长和衣摆长度正确。
- [ ] 领口、纽扣、绑带、褶皱、开衩和层数正确。
- [ ] 面料视觉接近原图，如棉、针织、牛仔、缎面、雪纺或皮革。
- [ ] 一体式服装未被虚构拆成不存在的上下装。
- [ ] 没有擅自增加 Logo、文字、图案或装饰。

## D. 单品拆解

- [ ] 所有显著上装、下装、鞋履和配饰均已出现。
- [ ] 包袋、帽子、眼镜、腰带、围巾、首饰、手表和道具没有遗漏。
- [ ] 每件商品无人体、无衣架、无包装和无网页信息。
- [ ] 鞋履成双展示。
- [ ] 没有同一单品重复出现。
- [ ] 没有把另一位人物的单品混入当前图片。
- [ ] 被遮挡部分采用保守补全，没有凭空增加复杂结构。

## E. 版式和文字

- [ ] 背景为纯白或极浅暖白。
- [ ] 中央人物为画面视觉主体。
- [ ] 左右栏目分区清楚，商品不压住人物。
- [ ] 留白充分，画面不拥挤。
- [ ] 标题为黑色细衬线大写字母。
- [ ] 每个标题下方有整齐细横线。
- [ ] 法文拼写正确：HAUTS、BAS、CHAUSSURES、ACCESSOIRES。
- [ ] 特殊栏目拼写正确：TENUE、ROBE、DÉTAILS、INSTRUMENTS、OBJETS。
- [ ] 没有乱码、随机文字、价格、品牌说明或额外文案。

## F. 摄影质感

- [ ] 人物和商品均为真实摄影质感。
- [ ] 光线柔和统一，阴影轻微自然。
- [ ] 材质清楚，但没有过度锐化或塑料感。
- [ ] 没有插画、卡通、3D 玩具或明显 AI 拼贴感。
- [ ] 整体达到干净、克制、高级的时尚编辑效果。

## 关键失败项

出现以下任一问题，必须重新生成：

1. 比例不是 9:16。
2. 同一张图出现两名中央人物。
3. 用户要求正脸但仍然遮脸或低头。
4. 人物头顶、脚部或服装主体被裁切。
5. 服装颜色、图案或主要结构被明显改写。
6. 单品与人物穿搭不一致或混入其他人的物品。
7. 原图背景、截图界面或水印仍然存在。
8. 文字严重拼错或出现大面积乱码。

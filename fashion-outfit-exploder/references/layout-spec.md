# 锁定版式规范

## 画布

- 比例：严格 9:16。
- 推荐尺寸：1024×1820、1080×1920 或同等比例。
- 背景：纯白或极浅暖白，无纹理、无渐变、无环境场景。
- 四周保留安全留白，任何文字、人物头顶、鞋底和商品均不得贴边。

## 中央人物

- 位于画面中轴，视觉中心略高于几何中心。
- 从头顶到鞋底完整出现。
- 建议占画面高度的 70%–82%。
- 正脸或自然近正面，眼睛清晰，不被手机、手、帽檐遮挡。
- 站姿自然，身体可有轻微动态，但不可侧身到看不清穿搭结构。
- 原图若为坐姿、低头或自拍，仍统一重建为适合穿搭展示的完整站姿。

## 左侧栏目

默认分为上下两区：

1. 左上：`HAUTS`，展示外套、衬衫、T 恤、背心、针织或整套上半身层次。
2. 左下：`BAS`，展示裤装、半裙、短裙或真实存在的叠穿裙层。

一体式服装：

- 左上可改为 `TENUE` 或 `ROBE`，展示整件服装。
- 左下可改为 `DÉTAILS`，展示领口、腰部、开衩、纽扣或面料局部。
- 不允许为填满版面而虚构不存在的上下装。

## 右侧栏目

默认分为上下两区：

1. 右上：`CHAUSSURES`，展示成双鞋履。
2. 右下：`ACCESSOIRES`，展示包袋、帽子、眼镜、腰带、围巾、首饰、手表等。

显著道具：

- 乐器使用 `INSTRUMENTS`。
- 杯子、伞、球拍等可使用 `OBJETS`。
- 若道具体积较大，可占据右上整区，鞋履下移，但人物仍保持居中。

## 标题系统

- 黑色或近黑色。
- 大写法文。
- 细衬线字体，接近高端时装杂志排版。
- 字号克制，不抢人物视觉中心。
- 每个标题下方放一条细横线，横线宽度略大于标题。
- 标题必须拼写正确：
  - `HAUTS`
  - `BAS`
  - `CHAUSSURES`
  - `ACCESSOIRES`
  - `TENUE`
  - `ROBE`
  - `DÉTAILS`
  - `INSTRUMENTS`
  - `OBJETS`

## 商品静物

- 每件商品独立抠出，背景与画布统一。
- 正面或轻微 3/4 角度。
- 统一柔和棚拍光和轻微自然阴影。
- 不使用衣架、人体模特、包装盒、价格标签或购物网站信息。
- 同一区域内商品尺寸按重要性排列，避免所有物品等大。
- 商品不得压住中央人物。
- 单品之间保持明显间距，不堆叠、不拥挤。

## 视觉风格

- 极简时尚编辑感。
- 高级但不奢华浮夸。
- 真实摄影和电商静物质感，不使用插画、卡通、3D 玩具风或过度磨皮。
- 色彩由原穿搭决定，不额外加入主题色块。
- 阴影轻、对比适中、材质清楚。

## 必须排除

- 原图街景、室内、镜子、车辆、建筑和其他背景元素。
- 社交媒体截图按钮、页码、黑边、水印和账号文字。
- 箭头、注释框、价格、品牌名、色卡和额外文案。
- 多人物同框。
- 裁切头顶、鞋底或服装下摆。
- 重复商品、错误商品和与原图无关的装饰。
